# 🚗 Car-showroom 

Автомобильный салон — это REST API для управления автопарком, клиентами, заказами и платежами.

**Автор:** Аксизов Эрвин

---

## 📖 Описание проекта

Добро пожаловать в **Car-showroom** — API для управления автосалоном 🚘  
Здесь вы можете работать с автомобилями, клиентами, заказами, оплатами и доставкой через удобный REST API.

Проект разработан как учебный, но уже отлично подходит для практики и демонстрации навыков разработки 😉

---

## ⚙️ Возможности

Проект позволяет управлять:

- 🚗 Брендами и моделями автомобилей  
- 📦 Автомобилями в каталоге  
- 👤 Клиентами  
- 🧾 Заказами и платежами  
- 🚚 Доставкой автомобилей  
- 💰 Прайс-листами  

---

## 🛠 Технологии

В проекте используются:

- **Node.js** — серверная платформа  
- **Express.js** — веб-фреймворк  
- **PostgreSQL** — база данных  
- **Sequelize** — ORM  
- **Docker** — контейнеризация  
- **Swagger** — документация API

## 📦 Установка и запуск

### 1. Клонируйте репозиторий

git clone https://github.com/tikyy01/Car-showroom

Перейдите в папку проекта:
```
cd Car-showroom
```
Запустите проект через Docker:
```
docker compose up -d --build
```
Готово! Сервер доступен по адресу:
http://localhost:6868
Сервер успешно запущен и готов к работе 🚀

📘 Документация API
Swagger-документация доступна по адресу:
http://localhost:6868/api-docs
