# Car-showroom

Автомобильный салон — каталог автомобилей, управление, прайс-листы, заказы, платежи и выдача автомобилей клиентам.

**Автор:** Аксизов Эрвин

## Описание проекта

Проект представляет собой REST API для автосалона. Позволяет управлять:
- Брендами и моделями автомобилей
- Автомобилями в каталоге
- Клиентами
- Заказами и платежами
- Доставкой автомобилей
- Прайс-листами

## Технологии

- **Node.js** - серверная платформа
- **Express.js** - веб-фреймворк
- **PostgreSQL** - база данных
- **Sequelize** - ORM
- **Docker** - контейнеризация
- **Swagger** - документация API
